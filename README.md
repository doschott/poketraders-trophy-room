# PokeTraders Trophy Room

Walk the den, step outside into a real 3D yard, board the house vehicle, and run a scored course. Invite a friend with a room code.

Homes: NYC loft, La Jolla, Grand Cayman, Mars.

## Play

Open the live site, pick a home, enter a name, and start. Share the room code so a friend can ride along.

## Stack

TanStack Start, Three.js, WebRTC P2P, Vercel.
